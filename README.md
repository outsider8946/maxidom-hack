# Dependeices:
- Python 3.11+
- uv


# Installation:

## Install dependencies for your platform
**Windows/Linux** :
```bash
uv sync --extra frida-torch
```

**MacOS** :
```bash
uv sync --extra frida-mlx
```

## Usage
To run UI locally execute in root of project:
```bash
uv run streamlit run app.py
```
