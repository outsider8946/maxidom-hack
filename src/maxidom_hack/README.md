## Калькулятор материалов

Калькулятор получает размеры комнаты и нормализованные товары каталога, после
чего рассчитывает количество упаковок и итоговую стоимость материалов.
Логика расчета не зависит от ChromaDB, Ollama или эмбеддингов: ML-часть может
найти товары отдельно, а калькулятор принимает готовый список
`CatalogProduct`.

### Что сделано

- `coefficients.py` хранит единые значения запасов, количества слоев краски и
	расхода материалов по умолчанию.
- `parser.py` преобразует записи из `data/products_final.json` в
	`CatalogProduct`. Он читает цену, единицу измерения, характеристики,
	площадь упаковки, объем, вес и расход. Категории переводятся во внутренние
	значения калькулятора (`wall_paint`, `floor_tile`, `tile_glue` и т.д.).
- `calculator.py` содержит расчеты для плитки, клея, затирки, ламината,
	краски, обоев, плинтуса и электрики. Количество упаковок всегда округляется
	вверх через `math.ceil`.
- `main.py` предоставляет HTTP API и сохраняет существующую инициализацию
	`LLMClient` и `DBLoader`.

### Как работает расчет

Для жидких и сыпучих материалов используется формула:

`необходимое количество = площадь × расход на м² × количество слоев`

Затем результат делится на объем или вес одной упаковки и округляется вверх.
Для плитки, ламината и других площадных материалов сначала добавляется запас,
после чего площадь делится на площадь одной упаковки. Каждая позиция сметы
содержит поле `reason` с использованной формулой и параметрами расчета.

При полном расчете:

- косметический вариант включает покраску, обои, ламинат и плинтус;
- капитальный вариант для ванной или кухни включает плитку на пол и стены;
- капитальный вариант для жилой комнаты включает ламинат и покраску стен и
	потолка;
- для всех вариантов добавляется расчет плинтуса и электрики.

Перед выбором материала товары фильтруются по назначению комнаты и влажности.
Для влажных помещений исключаются невлагостойкие плитка и краска, а для кухни
исключается немоющаяся краска. Из оставшихся товаров выбирается вариант с
минимальной ценой за площадь или единицу материала.

### API

`POST /api/v1/calc/estimate` принимает комнату и вариант ремонта:

```json
{
	"room": {
		"length": 3,
		"width": 2,
		"height": 2.7,
		"purpose": "bathroom",
		"humidity": "high"
	},
	"variant": "capital"
}
```

`POST /api/v1/calc/product` принимает идентификатор товара и площадь:

```json
{
	"product_id": 123,
	"area": 20,
	"waste": 0.05,
	"layers": 2
}
```

Оба endpoint возвращают рассчитанные позиции, количество упаковок, стоимость
и пояснение в `reason`.
